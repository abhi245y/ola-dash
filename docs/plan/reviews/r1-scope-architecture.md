# Review r1: scope, architecture, ordering (Fable)

Reviewed: PLAN.md draft r1. Ranked, most important first. Line numbers refer to draft r1.

1. **D1 split breaks the SDK.** `sim/src/main.rs:36` includes `host/src/theme_root.rs`; `:551,:561` compile the root from `host/ui/`. Moving `host/` kills `check-themes`, the themes CI job and the host CI job, and "SDK keeps its host until parity" means two hosts. Change: host stays in the SDK; `ola-dash` holds the product theme pack, installer, recovery watchdog, store index + submission CI (no third repo), release pipeline, user docs; it pins the SDK and builds `host/build.sh` with product themes bundled (one `EXTRA_THEMES` copy next to build.sh:42; `MainActivity.copyAssets` already copies assets into `files/`). Host stories become SDK PRs.
2. **The ">1.5 s, separate compile-once layer" branch is unbuildable.** Slint 1.18.1 Android backend has one window adapter; compiled components cannot be embedded in an interpreted tree. Host screens live in the interpreted root. E0.S5 must: use `slint::run_event_loop()` + manual `show()` and drop the old root without `hide()` (lib.rs:490-493 uses `ui.run()`; `hide()` clears the shared window's component); show a static card for one loop tick before compiling (compile is `spin_on` on the UI thread); verify on device (sim opens real separate windows); re-measure M-compile after E1. Laziest alternative: if M-start ≈ M-compile + 0.5 s, switch = write `files/themes/active` + `Activity.recreate()`, drop E0.S5 (check `slint::android::init` tolerates a second call).
3. **`LAST` table duplicates Java.** `VehicleBridge.java:376-381` keeps `REAL[]` and replays after test mode. Expose `replayReal()`; ask PluginHost to resend its snapshot.
4. **D3 mechanics.** `set_property` reaches only root public properties; inner `Dash` is unreachable. Extend the `MIRRORS` generator (theme_root.rs:76-85) to emit `in property <T> opt-<id>` on `Host` and bind `dash := Dash { opt-<id>: root.opt-<id>; }`. `ValueType` collapses int/float/length to Number, color to Brush; enums cannot be declared dynamically, so `choice` is a string. Drop "max 12 options".
5. **D2 sound.** Host screens read `LockConfig.style.*` (theme_root.rs:177-200). The hub button sits in the strip, styled by `OverlayConfig`. Night for host screens needs nothing new: a theme binds `lock-style` on `Display.night`.
6. **ParkGate duplicates TrunkGate.** `parked = TrunkGate park rule || charging`; `TrunkGate.refusal` calls it. One definition, one JVM test.
7. **Ordering.** Contract v7 before the shell (shell needs its callbacks). Launcher belongs in M2 with the dash bar (no launching apps with no telltales). Dash bar edge/size depends on the AA spike's margin finding: run the spike in the M2 scooter session. AA settings section belongs in E6.S2. Release flavor not needed in M1: merge with the release pipeline, schedule before E4 (cert digest).
8. **Launcher over-built.** Java `Activity` + `GridView` over `PackageManager` (~100 lines, no cache, no JNI); parked gate `finish()`es it; the dash bar covers it like any app. Slint only if it must be theme-styled.
9. **Index signing adds a crate, key ceremony, signing tool and repo without raising the bar** above "maintainer's GitHub over HTTPS" that the installer already trusts. 1.0: index + SHA-256 + plugin cert digest, hosted in `ola-dash`; sign when a mirror or second maintainer appears.
10. **Owner PIN not asked.** Move to backlog with an owner question; "Open Android settings" becomes parked only.
11. **Night for every E3 theme doubles design work.** Night optional per theme; absent = day look.
12. **E3 scope.** 1.0 pack = Twin dial, Terminal, Zen, Cockpit (after E7), default refresh; fold Sport into Twin dial options. Cockpit uses only what the contract carries.
13. **Goal must say** the installer needs a rooted scooter and comes last; Linux first.
14. **Droppable/mergeable.** `new-theme.sh`: skill already has `templates/theme/`. E5.S3 into E4.S4. E6.S3 is a spike finding. Switcher is one host screen. 
15. **Sizing.** Split E1.S3 (core sections + settings.json; other sections land with the stories that own them), E0.S5, E4.S3 (index/list vs install/update/uninstall), E5.S2 (preflight+backup vs install+grants+watchdog vs uninstall). Merge E0.S1.T3 into T1, E0.S2 tasks, E2.S2 into E1.S2 + Display section.

Verdict: over-builds on repo structure and on three mechanisms the code already covers (REAL[] replay, MIRRORS, TrunkGate) or the platform cannot provide (second window, setting inner Dash properties). Ordering wrong in four places. Owner PIN, Sport, index signing, a third repo and a tri-OS installer are droppable.
